# Contributing

1. Keep own project code under LGPL-2.1-or-later; do not re-license
   `third_party/gmsh/` as LGPL.
2. Prefer explicit options documented in `docs/job-format.md`; do not add
   undocumented job keys or sections without updating that doc.
3. Update `CHANGELOG.md` and, for Gmsh API changes, `third_party/gmsh/README.GFE.md`.
4. Run the tests under `test/` once they are implemented.
